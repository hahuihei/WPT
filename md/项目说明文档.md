## 1. 项目概述

将论文 **"Constrained Model Predictive Control for Current Regulation of DC-DC Converter for Wireless Power Transfer System"** 的 MPC 算法迁移到 **TMS320F28335 DSP** 独立运行。

核心链路：**ADC 采样 → 负载自动识别 → SSTC 稳态目标计算 → MPCC 动态约束 QP → PWM 占空比输出**，实现对 Buck 输出电流的跟踪控制。

相比纯 MPC，本工程增加了 **SSTC（Steady-State Target Calculation，稳态目标计算）层**，将「算稳态前馈占空比」从动态 MPC 中解耦出来，使前馈更准确、负载切换更平稳。

## 4. 控制架构（数据流）

每个控制周期的完整链路：

```
ADC_ReadBlocking()             40 点平均，转物理量 (V, I)
        │
        ▼
负载检测 (main.c)              r_eff = V / I，量化到 5/10/15Ω，带去抖+锁存
        │  检测到 RL 变化时：
        │    ├─ SSTC_SetRL(RL)        重算稳态增益 K
        │    └─ MPCC_RecomputeModel(RL) 重算预测矩阵 g_MM/g_MP
        ▼
SSTC_Compute()                ys_ref(稳态目标) + us_ref(前馈占空比)
        │
        ▼
MPC_SolveFullQP()             qpOASES 解 13 变量约束 QP → u_opt[0..2]
        │
        ▼
duty = u_opt[0]  →  PWM_UpdateDutyCycle(duty)  →  ePWM 输出
```

### 4.1 SSTC 层（稳态目标）

`SSTC_Compute()` 计算 Buck 的 **DC 稳态增益** `K = [UF, UF/RL]`，进而得到稳态目标：

```
K[0] = UF          （电压通道：稳态电压 = UF × duty）
K[1] = UF / RL     （电流通道：稳态电流 = (UF/RL) × duty）
```

理想稳态占空比 `us = 电压目标 / UF`，稳态电流 `ys_i = K[1] × us = 电压目标 / RL`。

> **重要**：当前代码 [sstc.cpp](file:///d:/wenjian/OneDrive/workspace_v6_1_3/DSP8233x_BUCKSSTC/APP/sstc/sstc.cpp) 中 `SSTC_ENABLE = 1`，即**已启用 SSTC 的软约束 QP 优化**（带松弛变量 η，跟踪稳态目标）。置 `SSTC_ENABLE = 0` 可退回理想占空比前馈 `us = voltage_tgt / BUCK_UF`（调试用）。

### 4.2 MPCC 层（动态 QP）

`MPCC_Controller()` 构造并求解一个 **13 变量、10 等式约束**的二次规划：

```
变量 z = [y1×5; y2×5; u×3]        (y1=电压, y2=电流, u=占空比)
min   0.5·zᵀ·H·z + gᵀ·z
s.t.  lb ≤ z ≤ ub                箱约束 (电压/电流/占空比限幅)
      Aeq·z = g_be               等式约束 = 预测模型 Y = g_MM·x + g_MP·U
```

其中 `H` 叠加了 **Δu 占空比变化率惩罚**（`DU_WEIGHT_H = 1.0`），防止占空比突变。

### 4.3 QP 求解器（qpOASES）

- 版本 3.2，LGPL v2.1，核心 `.cpp` 未修改。
- `qpoases_port.cpp` 负责构造 `H/Aeq/lb/ub/lbA/ubA` 并调用 `QProblem`。
- **回退机制**：QP 求解失败时，用 `us_ref`（SSTC 稳态值）兜底，而非输出 0，避免负载切换时电流跌落。

## 5. 代码调用流程

```c
main()
  ├─ InitSysCtrl() / InitFlash() / InitGpio()
  ├─ CpuTimer2 启动              # 150MHz 自由运行计数器，用于测量控制周期耗时
  ├─ MPCC_Init()                 # PreCompute(BUCK_RL) + QPOASES_Init() + SSTC_Init()
  ├─ MPCC_SetControlMode(current)  # 设置 Q/R 权重
  ├─ PID_Init()
  ├─ PWM_GPIO_Init() / PWM_Init() / ADC_Init()
  ├─ PWM_Start() → delay → ADC_MeasureCurrentBias()   # 电流零偏校准
  └─ while(1):
      ① ADC_ReadBlocking(&V, &I)          # 40点平均，转物理量
      ② current_filtered = I              # 当前未做低通滤波
      ③ 负载检测（去抖+锁存），RL 变化时更新 SSTC/MPCC 模型
      ④ MPCC_Controller(target, v_tgt, V, I_filtered, &duty)
           └─ SSTC_Compute() → ys_ref, us_ref
           └─ MPC_SolveFullQP() → u_opt
      ⑤ PWM_UpdateDutyCycle(duty)
      ⑥ 更新监控变量 + 记录耗时历史
```

## 8. 如何验证与调参

### 8.1 验证 QP 是否正常（铁证三连）

在 CCS Expressions 窗口添加：

```
monitor_qp_exit     → 必须 = 0
monitor_xu_raw[0]   → ≈ 前馈占空比 (10Ω 时 ≈ 0.6)
monitor_xu_raw[1]   → 与 [0] 有差异
monitor_xu_raw[2]   → 与 [0][1] 都有差异（说明 QP 在优化 3 个控制量）
```

若 `monitor_xu_raw[0]==[1]==[2]` 三点完全相同，说明回退到了闭式/前馈解，检查 heap size 与调用路径。

### 8.2 调参

| 现象 | 调整 |
|------|------|
| 电流稳态低于目标 | 减小 `R_scalar`（增强反馈）或校正 `BUCK_UF` |
| 占空比大幅振荡 | 增大 `R_scalar` 或减小 `Q_diag[1]` |
| 负载切换超调大 | 增大 `DU_WEIGHT_H`（Δu 惩罚） |

### 8.3 输入电压变化适配

若更换电源电压，修改 `mpcc.h` 中 `BUCK_UF` 为实际母线电压（含损耗的等效值）。SSTC 层会自动用 `voltage_target / BUCK_UF` 计算前馈占空比。

## 9. 常见问题

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| `qp_exit` ≠ 0 | QP 不可行或超迭代 | 检查 `y_max[1]` 是否 > 目标电流 |
| `xu_raw` 三点完全相同 | 回退到前馈解 | 检查 heap ≥ 0x1000、调用 `MPC_SolveFullQP` |
| 电流完全不对 | ADC 标定错误 | 核对 `VOLTAGE_SCALE` / `CURRENT_SCALE` |
| 切换负载后电流跌落 | QP 重建失败 | 检查回退逻辑是否生效 |
| 编译内存不足 | Flash/RAM 溢出 | 检查 F28335.cmd 内存分配 |
