# DSP 模型预测电流控制 (MPCC) — 工程完整说明

## 项目概述

将论文 **"Constrained Model Predictive Control for Current Regulation of DC-DC Converter for WPT System"** 的 MPC 算法从 MATLAB/PC 迁移到 **TMS320F28335 DSP** 独立运行。

核心：ADC 采电压电流 → qpOASES 解 8 变量约束 QP → PWM 占空比输出，电流跟踪设定值。

---

## 1. 硬件连接

| 功能 | DSP 引脚 | GPIO | 说明 |
|------|---------|------|------|
| 电压采样 | ADCINA0 | — | Buck 输出电压分压后 0~3V |
| 电流采样 | ADCINA1 | — | 电流传感器输出 0~3V |
| PWM 上管 | EPWM1A | GPIO0 | Buck 主开关驱动 |
| PWM 下管 | EPWM1B | GPIO1 | 同步整流，带 200ns 双边死区 |

| 参数 | 值 | 说明 |
|------|-----|------|
| 输入电压 | 22V DC | 可调 |
| 负载 | 20Ω | 默认 |
| 目标电流 | 0.75A | main.c 可改 |
| PWM 频率 | 100kHz | EPWM1 |
| ADC 标定 | V_SCALE=10.091, I_SCALE=4.0816 | adc.c |

## 3. 代码调用流程

```
main() 启动
  └─ MPCC_Init()         → PreCompute() 算 A/B/C/D/g_MM/g_MP
     + QPOASES_Init()
  └─ PWM_Init()          → 100kHz ePWM1
  └─ ADC_Init()          → 12位连续模式
  └─ ADC_MeasureCurrentBias()   → 零偏校准

main() 主循环 while(1):
  ① ADC_ReadResultsAveraged(&V, &I)   // 200次平均，转物理量
  ② I_filtered = 0.7*I_old + 0.3*I     // 一阶低通 α=0.3
  ③ MPCC_Controller(target, V, I_filtered, &duty):
       ├─ 算 g_be = g_MM × [V; I]       // 自由响应 (mpcc.c:358)
       ├─ 算 us_ref = target × RL/UF    // 稳态占空比 (mpcc.c:346)
       └─ MPC_SolveFullQP()             // (mpcc.c:357)
            └─ QPOASES_Solve()          // → qpoases_port.cpp
                 └─ QProblem::hotstart() // qpOASES active-set 迭代
       └─ duty = u_opt[0]               // 滚动时域：只取第一个
  ④ PWM_UpdateDutyCycle(duty)          // 更新 PWM
  ⑤ 更新 monitor 变量                   // CCS 调试用
```

## 4. QP 求解器 (qpOASES)

### 4.1 来源
- qpOASES 3.2，开源 (LGPL v2.1)，来自 GitHub: coin-or/qpOASES
- 13个核心 .cpp 文件 **完全未修改**（MD5 校验一致）
- 仅 Types.hpp 启用了4个官方预留编译开关：
  - `__USE_SINGLE_PRECISION__`（real_t=float，匹配 C2000 FPU）
  - `__NO_SNPRINTF__`（C2000 无 snprintf）
  - `__NO_FMATH__`（C2000 无 `<cmath>`）
  - `__SUPPRESSANYOUTPUT__`（嵌入式无控制台）

### 4.2 接入层
- `qpoases_port.h` — C 接口声明（extern "C"）
- `qpoases_port.cpp` — C++ 实现，构造 H/f/Aeq/lb/ub/lbA/ubA，调用 QProblem 类

### 4.3 调用的 QP 问题
```
变量 z = [y(0);y(1);y(2);y(3);y(4); u(0);u(1);u(2)]  — 8个
min  0.5 × zᵀ × H × z  +  gᵀ × z
s.t. lb ≤ z ≤ ub                     箱约束
     lbA ≤ Aeq × z ≤ ubA             等式约束 = 预测模型
     
H = diag(2Q,2Q,2Q,2Q,2Q, 2R,2R,2R)
g = -H × [ys_ref×5; us_ref×3]
Aeq = [I₅, g_MP]
lbA = ubA = g_be
lb = [y_min×5; u_min×3], ub = [y_max×5; u_max×3]
```

## 5. 如何编译和烧录

### 5.1 CCS 环境要求
- Code Composer Studio 6.x 或更高
- C2000 编译器 ti-cgt-c2000_15.12.1.LTS
- 工程目标：TMS320F28335，Flash 启动

### 5.2 必须的 CCS 设置

| 设置 | 路径 | 值 |
|------|------|-----|
| **Heap Size** | Project Properties → C2000 Linker → Basic Options | **0x1000** |
| Include Path | Project Properties → C2000 Compiler → Include Options | 添加 `${PROJECT_ROOT}/APP/qp/include` |
| 链接脚本 | 工程中使用 | `F28335.cmd` |

### 5.3 内存布局 (F28335.cmd 关键项)

| Section | 区域 | 大小 | 说明 |
|---------|------|------|------|
| `.text` | FLASH_CDEF + FLASHA | ~128KB | 程序代码（qpOASES 较大） |
| `.ebss` | RAML4_5 | 8KB | 全局/静态变量 |
| `.esysmem` (heap) | RAML7 | 4KB | qpOASES `new QProblem` 用 |
| `.stack` | RAMM1 | 1KB | 函数调用栈 |

### 5.4 COFF vs EABI ⚠️

工程中 qpOASES 的 `.cpp` 文件需
以 **C++ 模式编译**。CCS 会根据文件扩展名自动选编译器：

- `.c` → C 编译器
- `.cpp` → C++ 编译器

**确认**：`APP/qp/` 下所有 `.cpp` 文件的 Build Properties → Build → C++ Compiler 路径正确。

### 5.5 编译步骤
1. Clean Project
2. Rebuild Project
3. 无错误 → 烧录到 Flash

## 6. 如何验证 QP 是否正确

在 CCS Expressions 窗口添加以下变量（暂停 DDB 后查看）：

### 6.1 铁证三连（最重要）

```
monitor_qp_exit        → 必须 = 0
monitor_xu_raw[0]      → 约 0.75
monitor_xu_raw[1]      → 与[0]有几个小数位不同 ← 关键！
monitor_xu_raw[2]      → 与[0][1]都不同        ← 证明QP在优化8个变量
```

**如果 xu_raw[0]==xu_raw[1]==xu_raw[2]（三点完全相同），说明在跑闭式解而非 qpOASES。** 检查：
- Heap size 是否 ≥ 0x1000
- mpcc.c 第 357 行是否调用 `MPC_SolveFullQP`（不是 `MPC_SolveClosedForm`）

### 6.2 模型验证

```
手算: monitor_be[0] = monitor_state_voltage / 20
对比: Expressions 中的 monitor_be[0]
误差: < 0.01 为正常
```

### 6.3 所有关键监测变量

| 变量 | 含义 | 正常值 |
|------|------|--------|
| `monitor_qp_exit` | QP 退出码 (0=成功) | 0 |
| `monitor_xu_raw[0,1,2]` | QP 优出的 3 个控制量 | 三点微差异，约 0.75 |
| `monitor_mpcc_duty_cycle` | 最终输出占空比 | 0.6~0.9 |
| `monitor_mpcc_error` | 电流跟踪误差 (A) | 稳态 < 0.05 |
| `monitor_state_voltage` | 输出电压 (V) | 10~16V |
| `monitor_state_current` | 输出电流 (A) | 0.6~0.8A |
| `monitor_be[0]` | 自由响应 g_be[0] | = voltage/20 |
| `monitor_mpcc_target` | QP 跟踪目标 | 0.75 |
| `monitor_ff_u[0]` | 目标函数最小值 | 负数 |

## 7. 论文实验怎么做

论文有三组实验：

### 7.1 参考电流阶跃 (Section 4.2)

修改 `main.c` 中 `current_target` 的值，观察电流响应：

```
current_target = 0.5f;   → 稳到 0.5A
current_target = 1.0f;   → 观察上升过渡过程
current_target = 0.75f;  → 回到 0.75
```

用示波器通道：Ch1=电流传感器输出，Ch2=EPWM1A 占空比。

### 7.2 负载突变 (Section 4.3)

并联/切换不同负载电阻（10Ω ↔ 20Ω），目标电流不变。

论文中：
- R_L=5Ω, duty≈37.5%, I=1.5A
- R_L=10Ω, duty≈75%, I=1.5A
- 5Ω→10Ω 调节时间约 30ms
- 10Ω→5Ω 调节时间约 40ms

你需要相应调整参数和设定值。

### 7.3 PID 对比实验

论文用 PID 作为基准对比。可临时在 main.c 中加上一个简单的 PI 控制器切换：
```c
// 切换开关
#define USE_MPC  1
#define USE_PID  0

if (USE_MPC) {
    MPCC_Controller(target, voltage, current_filtered, &duty);
} else {
    // PI: duty = Kp*error + Ki*integral
}
```

## 8. 如何调参

### 8.1 Q 权值（输出跟踪强度）

`mpcc.c` MPCC_SetControlMode() 中修改：

```c
Q[0][0] = 1.0f;    // 默认，稳态精度够
Q[0][0] = 20.0f;   // 跟踪更强，但可能振荡
Q[0][0] = 100.0f;  // 太激进，大概率振荡
```

现象 | 调整
------|------
电流总是低于设定值 | 加大 Q
占空比大幅来回振荡 | 减小 Q

### 8.2 us_ref（前馈稳态值）

`mpcc.c` 第 346 行：

```c
us_ref = target * BUCK_RL / BUCK_UF;
```

如果硬件输入电压改变（如输入 22V→16V），这个公式自动计算正确的稳态占空比。不需要手动改。

### 8.3 输入电压变化适配

如果更换电源（不再是 22V），修改 `mpcc.h` 中的 `BUCK_UF` 为等效有效值（标称电压的 ~90%，扣传导损耗）。

## 9. 常见问题

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| qp_exit ≠ 0 | QP 不可行或超迭代 | 检查约束 y_min/y_max 是否合理 |
| xu_raw 全是垃圾值 | new QProblem 失败 | heap 不足，增大 heap 到 0x1000 |
| xu_raw 三点完全相等 | 回退到闭式解 | 检查调用路径 |
| 编译报内存不够 | Flash/RAM 溢出 | 检查 F28335.cmd 内存分配 |
| 电流完全不对 | ADC 标定错误 | 确认 VOLTAGE_SCALE / CURRENT_SCALE |
