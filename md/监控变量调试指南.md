# DSP BUCK SSTC 工程 — 监控变量调试指南

本指南说明工程中所有 `monitor_*` 监控变量和关键物理量的含义、正常取值范围，以及如何通过它们判断系统是否正常工作。

---

## 一、数据流总览

每个控制周期（约 10µs）的完整链路：

```
ADC 采样 (电压/电流)
   │
   ├─► 负载检测 (r_eff = V/I → 量化 5Ω/10Ω)
   │
   ├─► SSTC 稳态目标计算 (QP)  ──► ys_ref(稳态目标) + us_ref(前馈占空比)
   │
   └─► MPCC 动态 QP  ──► u_opt[0] = duty
                             │
                             └─► PWM 输出
```

监控变量按「ADC → SSTC → MPCC → 状态」四层分布。

| `monitor_adc_timeout_count` | ADC 转换超时次数 | **应为 0**，非 0 表示转换异常 |
| `monitor_adc_st` | ADC 状态寄存器 `ADCST` | 用于诊断 |
| `monitor_adc_result0` | 电压通道最新单次转换值 | 诊断用 |
| `monitor_adc_result1` | 电流通道最新单次转换值 | 诊断用 |

## 三、SSTC 稳态目标层（[sstc.cpp](file:///d:/wenjian/OneDrive/workspace_v6_1_3/DSP8233x_BUCKSSTC/APP/sstc/sstc.cpp)）

SSTC 通过一个小型 QP 求解「最优稳态点 (ys, us)」，满足 `ys = K·us` 且尽量接近目标。

| 变量 | 含义 | 正常值（RL=10Ω, target=1.5A） |
|------|------|------------------------------|
| `monitor_sstc_Kv` | 电压通道 DC 增益 K[0] | = `BUCK_UF` = 20（恒定，与负载无关） |
| `monitor_sstc_Ki` | 电流通道 DC 增益 K[1] | = `BUCK_UF / RL`。10Ω→2，5Ω→4 |
| `monitor_sstc_ys_v` | 最优稳态电压目标 ys[0] | = target × RL。10Ω→15，5Ω→7.5 |
| `monitor_sstc_ys_i` | 最优稳态电流目标 ys[1] | = target（正常应等于 `current_target`） |
| `monitor_sstc_us` | 最优稳态占空比 us | = target × RL / UF。10Ω→0.75，5Ω→0.375 |
| `monitor_sstc_obj` | SSTC QP 目标函数值 | 负值，绝对值小表示偏差小 |

**关键判断：**

- `Kv` 恒定 = 20，`Ki` 随负载切换（2 ↔ 4）。
- `ys_i` 正常应等于 `current_target`。**如果 `ys_i` 明显大于 target，说明 QP 被约束 `y_max[1]` 卡住了**（电流上限）。
- `us` 与手算 `target × RL / UF` 吻合。

## 四、MPCC 动态控制层（[mpcc.c](file:///d:/wenjian/OneDrive/workspace_v6_1_3/DSP8233x_BUCKSSTC/APP/mpcc/mpcc.c)）

| 变量 | 含义 | 正常值 / 判断 |
|------|------|--------------|
| `monitor_mpcc_target` | 传给 MPCC 的电流跟踪目标 (= `ys_ref[1]`) | 应 = `monitor_sstc_ys_i` = current_target |
| `monitor_mpcc_error` | 电流跟踪误差 = target − current | 稳态应趋近 0 |
| `monitor_mpcc_us_ref` | 前馈占空比 (= `us_ref`) | 应 = `monitor_sstc_us` |
| `monitor_mpcc_duty_cycle` | 最终输出占空比 | 稳态 ≈ `us_ref` |
| `monitor_mpcc_delta_duty` | duty − us_ref（反馈修正量） | 稳态应 ≈ 0 |
| `monitor_mpcc_qp_status` | MPCC QP 求解状态 | 0 = 成功 |
| `monitor_qp_exit` | QP 退出码 | **0 = 成功**，非 0 表示求解失败 |
| `monitor_qp_iter` | QP 迭代次数（工作集数） | 小值（< 10） |
| `monitor_xu_raw[3]` | 最优控制序列 u_opt[0..2] | 三个未来占空比，应平滑 |
| `monitor_ff_u[3]` | [u_opt[0], QP目标值, 迭代次数] | 诊断用 |
| `monitor_be[10]` | 自由响应 g_be（5 预测步 × 2 输出） | 诊断用 |
| `monitor_mp_row0[3]` | 脉冲响应矩阵 g_MP 第一行 | 诊断用 |

**关键判断：**

- `qp_exit = 0`：QP 求解成功（最重要）。
- `delta_duty` 稳态接近 0：前馈准确，MPCC 只做微调。
- `delta_duty` 明显 ≠ 0：反馈在补偿（通常是 `BUCK_UF` 与实际不符）。
- `xu_raw[3]` 三个值应彼此接近，若剧烈跳变说明控制序列振荡。

## 六、关键权重与约束（[mpcc.c:22-28](file:///d:/wenjian/OneDrive/workspace_v6_1_3/DSP8233x_BUCKSSTC/APP/mpcc/mpcc.c#L22-L28)）

> 注意：实际运行权重由 `MPCC_SetControlMode()` 覆盖初始值。

| 参数 | 初始值 | 实际值（SetControlMode 后） | 含义 |
|------|--------|---------------------------|------|
| `Q_diag[0]` | 0.0 | 0.0 | 电压权重（0 = 不控电压，仅约束） |
| `Q_diag[1]` | 0.5 | **1.0** | 电流权重 |
| `R_scalar` | 20.0 | **2.0** | 控制量（占空比）权重 |
| `y_max[1]` | 2.0 | 2.0 | 电流上限（A） |
| `u_min / u_max` | 0 / 1 | 0 / 1 | 占空比限幅 |

- **R 越小**：反馈越强，跟踪越准，但可能振荡。
- **R 越大**：控制越平滑，但稳态误差越大（前馈不准时）。

## 七、当前数据解读（5Ω，目标 1.5A）

| 变量 | 实测值 | 期望 | 判断 |
|------|--------|------|------|
| `sstc_Ki` | 4.0 | 20/5=4 | ✓ 负载识别正确 |
| `sstc_ys_i` | 1.5 | 1.5 | ✓ SSTC 正确（之前的 bug 已修复） |
| `sstc_us` | 0.375 | 1.5×5/20 | ✓ |
| `sstc_ys_v` | 7.5 | 1.5×5 | ✓ |
| `us_ref` | 0.375 | = sstc_us | ✓ |
| `duty` | 0.403 | ≈0.375 | 略高（反馈补偿） |
| `delta_duty` | 0.028 | ≈0 | 反馈在起作用（R=2 已减小） |
| `qp_exit` | 0 | 0 | ✓ QP 成功 |
| 实际电流 | 1.296A | 1.5A | ⚠️ 仍偏低 13.6% |

**剩余问题：稳态电流仍偏低。**

反推实际等效输入电压 `UF_实际 = V / duty = 6.79 / 0.403 ≈ 16.85V`，而模型 `BUCK_UF = 20V`。两者不匹配导致前馈偏小，即使反馈（duty 升到 0.403）仍无法完全补足。

**进一步优化方向：** 将 `BUCK_UF` 从 20 改为实测等效值（约 17~18V），或继续减小 `R_scalar` 增强反馈。

## 八、调试速查表

| 现象 | 可能原因 |
|------|---------|
| `qp_exit` ≠ 0 | QP 求解失败，检查约束/模型矩阵 |
| `sstc_ys_i` > target | SSTC 被 `y_max[1]` 电流上限卡住 |
| `delta_duty` 稳态很大 | `BUCK_UF` 与实际输入电压不符 |
| `Ki` 不随负载变化 | 负载检测逻辑未触发 |
| `adc_timeout_count` 递增 | ADC 转换异常 / 时钟配置问题 |
| 切换负载后电流跌 0 | QP 重建失败 + 无回退（已修复） |
| 电流稳态偏低 | `BUCK_UF` 偏大，或 `R` 太大反馈不足 |
