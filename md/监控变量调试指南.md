# 监控变量调试指南

> 本指南说明如何用 `monitor_*` 监控变量判断系统是否正常工作，并给出故障排查路径。
> 变量定义与参数取值见 [DSP_工程变量说明文档.md](file:///d:/wenjian/OneDrive/workspace_v6_1_3/DSP8233x_BUCKSSTC/md/DSP_工程变量说明文档.md)，架构背景见 [项目说明文档.md](file:///d:/wenjian/OneDrive/workspace_v6_1_3/DSP8233x_BUCKSSTC/md/项目说明文档.md)

---

## 一、数据流总览

每个控制周期的完整链路：

```
ADC 采样 (40点平均 → 电压/电流)
   │
   ├─► 负载检测 (r_eff = V/I → 量化 5/10/15Ω, 去抖+锁存)
   │
   ├─► SSTC 稳态目标计算 ──► ys_ref(稳态目标) + us_ref(前馈占空比)
   │
   └─► MPCC 动态 QP ──► u_opt[0] = duty
                          │
                          └─► PWM 输出
```

监控变量按「ADC → SSTC → MPCC → 状态」四层分布，下面逐层说明「看什么、正常是多少、异常怎么判」。

---

## 二、ADC 采样层

| 变量 | 正常值 / 判断 |
|------|--------------|
| `monitor_adc_voltage` | 应等于 `monitor_state_voltage` |
| `monitor_adc_current` | 应等于 `monitor_state_current` |
| `monitor_adc_raw_voltage` | 电压通道原始 ADC 均值（0~4095），满量程对应 3.0V |
| `monitor_adc_raw_current` | 电流通道原始 ADC 均值 |
| `monitor_adc_current_bias` | 上电测量的电流零点偏置，稳定值 |
| `monitor_adc_sample_count` | 持续递增（采样正常） |
| `monitor_adc_timeout_count` | **应为 0**，非 0 表示 ADC 转换异常 |

**标定公式**（[adc.c](file:///d:/wenjian/OneDrive/workspace_v6_1_3/DSP8233x_BUCKSSTC/APP/adc/adc.c)）：

```
电压 = (raw / 4095) × 3.0 × 10.091
电流 = ((raw / 4095) × 3.0 − bias_v) × 3.9916
```

## 三、SSTC 稳态目标层

SSTC 计算 Buck 的 DC 稳态增益 `K = [UF, UF/RL]`，并给出稳态目标 `(ys, us)`，满足 `ys = K·us`。

| 变量 | 含义 | 正常值（RL=10Ω, target=1.5A） |
|------|------|------------------------------|
| `monitor_sstc_Kv` | 电压通道 DC 增益 K[0] | = `BUCK_UF` = 25（恒定） |
| `monitor_sstc_Ki` | 电流通道 DC 增益 K[1] | = `BUCK_UF / RL`，10Ω→2.5，5Ω→5.0 |
| `monitor_sstc_ys_v` | 稳态电压目标 ys[0] | = 电压目标 = 15V |
| `monitor_sstc_ys_i` | 稳态电流目标 ys[1] | = `current_target` = 1.5A |
| `monitor_sstc_us` | 稳态占空比 us | = `voltage_tgt / UF` = 0.6 |

**关键判断：**

- `Kv` 恒定 = 25，`Ki` 随负载变化（2.5 ↔ 5.0 ↔ 1.67）。
- `ys_i` 正常应等于 `current_target`。若 `ys_i` 明显大于 target，说明 SSTC 被 `y_max[1]` 电流上限卡住。
- `us` 与手算 `voltage_target / BUCK_UF` 吻合。

> 注：当前 [sstc.cpp](file:///d:/wenjian/OneDrive/workspace_v6_1_3/DSP8233x_BUCKSSTC/APP/sstc/sstc.cpp) `SSTC_ENABLE = 1`，SSTC 通过带松弛变量 η 的 QP 求最优稳态点，稳态下 `ys_i ≈ current_target`、`us ≈ voltage_tgt / BUCK_UF`。

## 四、MPCC 动态控制层

| 变量 | 含义 | 正常值 / 判断 |
|------|------|--------------|
| `monitor_mpcc_target` | 电流跟踪目标 (= `ys_ref[1]`) | = `monitor_sstc_ys_i` = `current_target` |
| `monitor_mpcc_error` | 电流误差 = target − current | 稳态应趋近 0 |
| `monitor_mpcc_us_ref` | 前馈占空比 (= `us_ref`) | = `monitor_sstc_us` |
| `monitor_mpcc_duty_cycle` | 最终输出占空比 | 稳态 ≈ `us_ref` |
| `monitor_mpcc_delta_duty` | duty − us_ref（反馈修正量） | 稳态 ≈ 0 |
| `monitor_mpcc_qp_status` | MPCC QP 求解状态 | 0 = 成功 |
| `monitor_qp_exit` | qpOASES 退出码 | **0 = 成功**，非 0 表示求解失败（已回退） |
| `monitor_qp_iter` | QP 工作集重算次数 | 小值（< 80） |
| `monitor_xu_raw[3]` | 最优控制序列 u_opt[0..2] | 三个值应平滑且彼此接近 |
| `monitor_ff_u[3]` | `[u_opt[0], 目标函数值, 迭代次数]` | 诊断用 |
| `monitor_be[10]` | 自由响应 g_be（5 步 × 2 输出） | 诊断用 |
| `monitor_mp_row0[3]` | 脉冲响应矩阵 g_MP 第一行 | 诊断用 |

**关键判断：**

- `qp_exit = 0`：QP 求解成功（**最重要**）。
- `delta_duty` 稳态接近 0：前馈准确，MPCC 只做微调。
- `delta_duty` 明显 ≠ 0：反馈在补偿（通常是 `BUCK_UF` 与实际母线电压不符）。
- `xu_raw[3]` 三个值应彼此接近；若剧烈跳变说明控制序列振荡。
- `xu_raw[0]==[1]==[2]` 三点完全相同：说明回退到了前馈解，检查 heap size 与调用路径。

## 五、状态与全局层

| 变量 | 含义 | 正常值 |
|------|------|--------|
| `monitor_state_voltage` | 实测输出电压（状态 x[0]） | = target × RL |
| `monitor_state_current` | 实测电感电流（状态 x[1]） | ≈ `current_target` |
| `monitor_global_Ub` | 实测输出电压 | 同 state_voltage |
| `monitor_global_iB` | 实测电感电流 | 同 state_current |
| `monitor_global_iB_filtered` | 滤波后电流 | 当前未滤波，= current |
| `monitor_global_us` | 输出占空比 | = duty |
| `monitor_system_uptime` | 主循环计数 | 持续递增 |
| `monitor_control_cycle` | 整个控制周期耗时（µs） | 稳定，无剧烈波动 |
| `monitor_sstc_time_us` | SSTC 单独耗时（µs） | 稳定 |
| `monitor_mpcc_qp_us` | MPCC 动态 QP 耗时（µs） | 稳定 |

## 六、调试速查表

| 现象 | 可能原因 | 排查方向 |
|------|---------|---------|
| `qp_exit` ≠ 0 | QP 不可行或超迭代 | 检查 `y_max[1]` 是否 > 目标电流 |
| `xu_raw` 三点完全相同 | 回退到前馈解 | 检查 heap ≥ 0x1000、是否调用 `MPC_SolveFullQP` |
| `delta_duty` 稳态很大 | `BUCK_UF` 与实际母线电压不符 | 校正 `BUCK_UF` |
| `Ki` 不随负载变化 | 负载检测逻辑未触发 | 检查 `r_eff` 计算与量化区间 |
| `adc_timeout_count` 递增 | ADC 转换异常 / 时钟配置问题 | 检查 ADC 初始化 |
| 切换负载后电流跌落 | QP 重建失败 + 回退异常 | 检查 `MPCC_RecomputeModel` 与回退逻辑 |
| 电流稳态偏低 | `BUCK_UF` 偏大，或 `R_scalar` 太大反馈不足 | 减小 `R_scalar` 或校正 `BUCK_UF` |
| 占空比振荡 | `R_scalar` 太小 / `Q_diag[1]` 太大 | 增大 `R_scalar` 或减小 `Q_diag[1]` |

## 七、系统是否正常的快速自检清单

按顺序检查，全部通过即系统基本正常：

1. `monitor_adc_timeout_count == 0`
2. `monitor_sstc_Kv == 25`（= `BUCK_UF`）
3. `monitor_sstc_Ki` 与当前负载匹配（5Ω→5.0，10Ω→2.5，15Ω→1.67）
4. `monitor_sstc_ys_i ≈ current_target`（1.5）
5. `monitor_mpcc_target == monitor_sstc_ys_i`
6. `monitor_qp_exit == 0`
7. `monitor_xu_raw[0/1/2]` 三点有微差异
8. `monitor_mpcc_delta_duty` 稳态接近 0
9. `monitor_state_current ≈ current_target`
10. `monitor_control_cycle`、`monitor_sstc_time_us`、`monitor_mpcc_qp_us` 均稳定

其中第 1~2 步排查硬件/标定，第 3~5 步排查 SSTC/负载识别，第 6~7 步排查 QP 求解，第 8~10 步排查控制性能。
